# Online Bookstore Management System

A Spring Boot-backed web application for managing online bookstore operations, containerized with Docker and ready for deployment.

---

## 🛠️ Prerequisites & Tech Stack
* **Java:** OpenJDK / Corretto 17
* **Framework:** Spring Boot
* **Build Tool:** Apache Maven (`pom.xml`)
* **Containerization:** Docker & Docker Compose
* **Database:** MySQL

---

## 🚀 Quick Start (Local / EC2)

### 1. Build and Run using Docker Compose
To launch both the application and database containers:

```bash
docker compose up --build -d
